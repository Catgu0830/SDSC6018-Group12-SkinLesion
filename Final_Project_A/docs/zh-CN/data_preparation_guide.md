## 1. 当前完成范围

已完成官方来源记录与校验、元数据检查、全部原图核验、按病灶划分数据、训练集拟合的预处理，以及训练集为主的 EDA。当前没有模型训练、模型性能比较或 Benefit/Harm/Neutral 结果。

HAM10000 共 10,015 张图像、7,470 个不同的 `lesion_id`、七类诊断。一条 CSV 记录代表一张图片；同一个病灶可以有多张图片。元数据没有患者编号，因此病灶级隔离不能等同于患者级隔离。

当前版本为 `v1_seed42`。划分比例、种子、标签编号和图像处理方案是 A 的首版实施选择，仍需与 B 确认。它们不是教师强制规定，也不能写成已经由全组确认。

## 2. 数据来源和原图放置

来源是 Harvard Dataverse 的 HAM10000，保存的官方记录为 V4.0：<https://doi.org/10.7910/DVN/DBW86T>。元数据文件 ID 是 4338392；原始 CSV 的官方 MD5 为 `8f85fb1aa29d80a2797247e434deb79d`。

默认下载接口返回 TAB；使用 `?format=original` 才获得对应官方校验值的 CSV。两份文件的字节不同，但解析后逐行、逐字段一致。CSV、TAB、官方记录及来源 JSON 已提交。

原图和 ZIP 不放入 Git。运行图片相关脚本前，将全部图片平铺到：

```text
Final_Project_A/data/raw/images/ISIC_xxxxxxx.jpg
```

不要在 `images/` 下再嵌套两个 part 文件夹。现有小组仓库的 `dataverse_files/` 与本包的数据目录不同；图片只放在前者，并不能满足这里保存的相对路径。

完整原包核验还需要把两个 ZIP 放在本包的 `data/raw/`。脚本 `audit_images.py` 不联网下载，只读取本地原包进行校验、解码和提取。只消费已冻结划分时，可以先准备原始 JPG 并按 `image_manifest.csv` 核验，无需把 ZIP 提交到仓库。

## 3. 已知数据质量问题

- 全部 10,015 张图片通过原包 CRC、JPEG 格式和完整像素解码检查，均为 600×450 RGB；文件清单保存原始字节的 SHA-256。
- 原始记录中年龄缺失 57 条，性别为 unknown 的有 57 条，部位为 unknown 的有 234 条；这些是图片记录数，不是患者数。
- 两个病灶存在不同的部位记录，九个病灶涉及多个来源子集。原记录保留，未擅自合并或删样本，详见英文元数据报告及 `metadata_audit.json`。
- 发现两对字节完全相同的 JPG，分别是 `ISIC_0029861 / ISIC_0024366` 和 `ISIC_0029938 / ISIC_0024777`。每对均在同一病灶内，当前保留且不会跨集合。
- 字节校验无法排除重新编码、裁剪或视觉近似的重复，也无法确认不同病灶是否属于同一患者。

## 4. 为什么按病灶划分

如果按图片随机分组，同一个病灶的不同照片可能分别进入训练集和测试集，导致评估时看到训练阶段已出现过的病灶。这里先按 `lesion_id` 分组，再按 `dx` 对病灶分层，最后把病灶归属映射回该病灶的全部图片。

比例指病灶数，目标是 70% / 15% / 15%。病灶照片数不同，因此图片比例自然会有偏差，不应拆开同一病灶来凑比例。

| 集合    |   病灶数 |   图片数 |   图片占比 |
| ----- | ----: | ----: | -----: |
| train | 5,229 | 7,050 | 70.39% |
| val   | 1,121 | 1,474 | 14.72% |
| test  | 1,120 | 1,491 | 14.89% |

训练集用于拟合处理参数和训练模型；验证集用于调参、早停和选择模型；测试集留给最终评估。不能按测试结果挑随机种子、预处理规则或模型。

## 5. 精确划分算法

先用整数四舍五入确定训练和验证的病灶数，测试接收剩余病灶。各诊断类别的训练配额通过最大余数法分配，使总数恰好为 5,229；再按剩余各类别病灶数，用同一方法分出 1,121 个验证病灶，其余进入测试。余数相同时按诊断代码字典序决定。

每类病灶按以下字符串的 SHA-256 十六进制值升序排列，字段替换为实际值；哈希相同时再按病灶 ID 排序：

```text
HAM10000-lesion-split-v1|42|dx|lesion_id
```

依次取训练配额、验证配额和剩余测试配额。输入 CSV 换行顺序不影响归属。这里采用一个固定种子，没有根据模型效果搜索种子。

三组的 `image_id`、`lesion_id` 和字节相同图像的哈希均无交叉；全部原始行和字段保持不变。完整算法与验证见[英文方法](../04_data_split_method.md)、[结果](../05_data_split_results.md)及 `split_validation.json`。

## 6. B 应读取哪些文件

不需要重新随机划分。使用：

```text
data/splits/v1_seed42/train.csv
data/splits/v1_seed42/val.csv
data/splits/v1_seed42/test.csv
data/splits/v1_seed42/label_mapping.json
```

三份划分 CSV 保留原始元数据，追加 `label`、`split`、`relative_path` 和 `image_sha256`。`combined.csv` 是完整图片名单；`lesions.csv` 是病灶级名单。`split_config.json` 记录算法、配额与输入哈希，`checksums.json` 校验冻结文件。

所有模型和消融使用同一套名单及标签编号：

这些数字是输出索引，不代表疾病严重程度。

## 7. 预处理与特征选择

可直接读取 `data/processed/v1_seed42/` 中的三份 CSV、`preprocessing_config.json` 和 `feature_schema.json`。这些 CSV 保留原字段并追加处理后的特征。

年龄参数仅从 7,050 条训练图片记录拟合：已知年龄 7,010 条、缺失 40 条；缺失值填为训练中位数 50。填补后训练均值为 51.754609929078015，总体标准差为 16.914031588126964。

```text
age_z = (age_imputed - train_mean) / train_std
```

验证和测试分别有 10、7 条年龄缺失，均应用同一组训练参数，不重新拟合。原始 `age` 保留，`age_missing` 和 `age_imputed` 用于审计。

性别和部位的类别词表也只从训练集取得，并保留 unknown；空类别或未来未见类别统一映射到 unknown，不扩展词表。

| 模式                | 特征维度 | 用途              |
| ----------------- | ---: | --------------- |
| all_metadata      |   19 | 年龄 1＋性别 3＋部位 15 |
| age_only          |    1 | 年龄消融            |
| localization_only |   15 | 部位消融            |
| image_only        |    0 | 仅图像基线           |

必须按配置中的 `feature_modes` 取列，不能把所有数值列都送进模型。`dx`/`label` 是答案；图片和病灶 ID、split、来源、确认方式、路径及哈希都是审计字段，不是预测特征。当前版本也没有把 `age_missing` 和 `age_imputed` 额外加入模型。

## 8. 图像输入接口

首版方案对应 `ResNet50_Weights.IMAGENET1K_V2`：短边缩放至 232、双线性插值、中心裁剪 224×224、RGB 除以 255，再使用 ImageNet 的固定均值与标准差归一化。训练额外执行水平翻转和直角旋转；验证与测试没有随机增强。

该权重与方案仍需和 B 对齐。实现使用 NumPy/Pillow，没有进行 TorchVision 逐像素等价验证。中心裁剪可能丢失病灶边缘，不能把训练样例预览当成对全部图片内容保留的保证。

以下示例在 `Final_Project_A/` 目录内运行；依赖 NumPy、Pillow：

```python
from pathlib import Path
import csv
import json
import sys

root = Path.cwd()
sys.path.insert(0, str(root / "scripts"))
from preprocessing import sample_arrays

config = json.loads(
    (root / "data/processed/v1_seed42/preprocessing_config.json").read_text()
)
with (root / "data/processed/v1_seed42/train.csv").open(newline="") as stream:
    row = next(csv.DictReader(stream))

sample = sample_arrays(
    row, config, data_root=root, mode="all_metadata", epoch=0, seed=42
)
print(sample["image"].shape)     # (3, 224, 224)
print(sample["metadata"].shape)  # (19,)
print(sample["label"])
```

可以将该接口包装进训练 Dataset；每轮更新 epoch，持久化数据进程也应同步 epoch。输出已经归一化，不能再次执行同样的归一化。

## 9. C 怎样连接预测

每个模型的测试预测应保留 `image_id`、真实标签、预测标签，并明确概率列的标签顺序。两个模型按 `image_id` 对齐，不依赖 CSV 当前行顺序；检查测试 ID 是否完整、唯一且与冻结 test 名单一致。

Benefit 为仅图像模型错误、多模态模型正确；Harm 相反；Neutral 为两者都正确或两者都错误。当前没有这些预测，因此尚无对应数量或分组结果。

年龄分组使用原始 `age`，缺失年龄单独处理，不把填补的 50 岁当作真实观测。性别及部位保留 unknown。亚组指标同时报告样本量；同病灶多图不能当成独立患者证据。

## 10. EDA 主要发现与使用范围

完整英文报告位于[EDA 报告](../../output/eda/v1_seed42/eda_report.md)。六组图有 PNG/SVG 两种格式，13 份统计表可逐项复查。

训练集 nv 有 4,724 张图片，占 67.01%；df 只有 86 张、51 个病灶，最多类与最少类的图片数约相差 54.93 倍。训练病灶中 1,390 个有多张照片。

原始已知年龄中位数为 50 岁，四分位区间 40–65 岁。训练集中年龄缺失 40、性别未知 43、部位未知 166；去重后共有 183 张图片至少一项缺失或未知，其中 33 张有多项，不能把字段计数直接相加。

这些结果描述数据结构，不证明多模态更好、模型更公平或具有临床效益。验证和测试只做了规模、类别构成的基础核对，没有用它们探索元数据效果或选择方案。
